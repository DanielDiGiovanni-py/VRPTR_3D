Public-facing cleanup of the supplied historical preprocessing scripts

Both files
- Removed private absolute paths, unused imports, stale comments, and unused
  constants; added argparse help, concise function documentation, logging, and
  import-safe main guards.
- Deferred scientific-library imports so importing the scripts or using --help
  does not require FSL/Nipype/Nilearn or start processing.
- Retained the scientific operations, numerical defaults, contrast definitions,
  and generated scientific output names. No claim of actual-data validation or
  exact study-environment reproduction is made.

preprocess.py
- Added explicit data/output/work/template paths, subject/run selection, TR and
  worker-count options, and a read-only --dry-run.
- Uses the FSLDIR standard template when --template is omitted.
- Extracted the processing graph into build_workflow without changing its graph
  connections or interface options. Nipype Function helpers retain their own
  imports so serialized worker execution does not depend on module globals.
- Removed unused ApplyXFM and ceil imports and the unused BATCH_SIZE constant.
- Replaced unconditional recursive deletion of prior work with a unique new
  per-subject work directory. Work is retained unless --cleanup-work is explicit;
  failed work is always retained. Cleanup only targets newly allocated work.
- Checks that discovered numeric entries are directories and validates requested
  paths. Existing cleaned-output skip behavior is retained.
- Removed the misleading fMRIPrep-style log label.

build_input_output.py
- Removed unused load_mni152_template and the commented atlas import.
- Generalized numeric subject discovery; --subject-id-length 3 restores the
  historical three-digit filter. Discovery now has a stable numeric order.
- Converted the inactive commented language-stage caller into an explicitly
  selectable --steps task stage, retaining its original GLM helper. Default
  behavior is still resting-stage processing only. This is an operational
  activation, not evidence that the study targets were generated by this file.
- Added --events-root for events stored separately from cleaned images.
- Added --atlas-cache, --force, and --skip-qc; retained QC-image skip conventions
  and documented their limitations.
- Replaced deprecated pandas delim_whitespace=True with equivalent sep=r"\s+".
- Added a nonempty/equal-count guard for task image and event lists; invalid
  inputs now fail explicitly instead of silently truncating via zip.
- Warns if multiple language-image matches exist (still uses the first sorted
  match, as the source did) or if the first design lacks story/math regressors.
- Extracted repeated surface plotting into one helper and removed the unused
  background-image option from the beta plotting helper.
- Uses a seeded NumPy generator solely for QC parcel selection instead of an
  uncontrolled global random draw. This changes only the selected QC figure.
- Corrected docstrings that claimed per-run matrices were saved, asserted
  detrending/standardization inside the resting masker, or implied named
  contrasts solve rank deficiency. Those claims were not supported by the code.
- Fingerprint population-SD normalization and T-1 divisor, original GLM timing,
  event-weight omission, and ConnectivityMeasure defaults remain unchanged.

Cleanup verification
- Python compilation and both --help commands completed successfully.
- Importing either script loaded no scientific dependency and ran no pipeline.
- A stand-in Nipype graph comparison matched all 13 node configurations and
  16 connections to the source graph; smoothing and cleaning worker bodies were
  AST-identical after removing docstrings.
- A synthetic-directory dry run created no output/work directories.
- Synthetic feature arrays and stand-in dependency-call traces matched source
  behavior for resting connectivity, fingerprints, and language contrast helpers.
- These checks verify cleanup preservation, not real-image scientific validity.
  FSL/Nilearn processing was not executed on study data in this environment.
